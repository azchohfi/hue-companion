Create `RenderCache` class that manages Win2D geometry caching.

Requirements:
- Implement IDisposable pattern for proper cleanup
- Store CanvasCachedGeometry instances for grid lines
- Provide methods to invalidate cache when zoom/duration changes
- Track whether cache is valid via `IsValid` property
- Include `Recreate(ICanvasResourceCreator creator, ...)` method for rebuilding cache

Key patterns from research:
```csharp
public class RenderCache : IDisposable
{
    private CanvasCachedGeometry? _gridLines;
    private float _cachedZoomLevel;
    private float _cachedDurationSeconds;

    public bool IsValid => _gridLines != null;

    public void Invalidate() { ... }
    public void Recreate(ICanvasResourceCreator creator, float zoomLevel, float duration, float height) { ... }
    public void Draw(CanvasDrawingSession ds, Color gridColor) { ... }
    public void Dispose() { ... }
}
```

Do NOT create geometry every frame - that defeats the purpose.

**TimeRulerRenderer:**
- `Draw(CanvasDrawingSession ds, float width, float height, float zoomLevel, int durationSeconds)`
- Renders tick marks every second, longer ticks every 5 seconds
- Renders time labels ("0s", "5s", "10s"...) at 5-second intervals
- Uses ds.DrawLine() for ticks, CanvasTextLayout for labels
- Port logic from `RenderTimeRuler()` in SceneBuilderPage.xaml.cs (lines 673-727)

**TrackLanesRenderer:**
- `Draw(CanvasDrawingSession ds, int trackCount, int eventTrackCount, float width, float trackHeight)`
- Renders horizontal separator lines between tracks
- Renders loop region background (subtle blue tint)
- Renders loop end boundary line
- Renders event track backgrounds (warm tint)
- Port logic from `RenderTimeline()` track separators and `RenderLoopRegion()` (lines 294-494)

**KeyframeLayerRenderer:**
- `Draw(CanvasDrawingSession ds, IEnumerable<TrackViewModel> tracks, IEnumerable<KeyframeViewModel> selectedKeyframes, float zoomLevel, float trackHeight)`
- Renders keyframe circles with color based on HueColor
- Selected keyframes render larger with highlight border
- Uses ds.FillCircle() and ds.DrawCircle() - NOT CanvasGeometry.CreateCircle() every frame
- Port logic from `RenderKeyframe()` (lines 729-768)

**PlayheadRenderer:**
- `Draw(CanvasDrawingSession ds, float playheadX, float height)`
- Renders vertical red line
- Renders triangle handle at top
- Uses ds.DrawLine() and ds.FillGeometry() with a pre-created triangle path
- Port logic from `RenderPlayhead()` (lines 346-394)

All renderers should:
- Accept drawing parameters, not own state
- Use Win2D primitives (FillCircle, DrawLine, DrawText) not XAML shapes
- Include XML documentation comments

Create `TimelineRenderer` that orchestrates all component renderers.

Requirements:
- Owns instances of all component renderers
- Owns RenderCache instance
- Provides `Draw(CanvasDrawingSession ds, TimelineRenderContext context)` method
- Creates `TimelineRenderContext` record/class to pass all needed data:
  - Tracks, EventTracks, SelectedKeyframes
  - ZoomLevel, DurationSeconds, PlayheadPosition
  - CanvasWidth, CanvasHeight, TrackHeight
  - SnapInterval, IsSnapEnabled
- Renders layers in correct order: grid -> tracks -> loop region -> keyframes -> event tracks -> playhead
- Provides `InvalidateCache()` method that forwards to RenderCache
- Implements IDisposable to clean up RenderCache

Structure:
```csharp
public class TimelineRenderer : IDisposable
{
    private readonly RenderCache _cache;
    private readonly TimeRulerRenderer _rulerRenderer;
    private readonly TrackLanesRenderer _trackRenderer;
    private readonly KeyframeLayerRenderer _keyframeRenderer;
    private readonly PlayheadRenderer _playheadRenderer;

    public void Draw(CanvasDrawingSession ds, TimelineRenderContext context) { ... }
    public void CreateResources(ICanvasResourceCreator creator, TimelineRenderContext context) { ... }
    public void InvalidateCache() { ... }
    public void Dispose() { ... }
}

public record TimelineRenderContext(
    IReadOnlyList<TrackViewModel> Tracks,
    IReadOnlyList<EventTrackViewModel> EventTracks,
    IReadOnlyCollection<KeyframeViewModel> SelectedKeyframes,
    float ZoomLevel,
    float DurationSeconds,
    float PlayheadPosition,
    float CanvasWidth,
    float CanvasHeight,
    float TrackHeight,
    float SnapInterval,
    bool IsSnapEnabled
);
```
