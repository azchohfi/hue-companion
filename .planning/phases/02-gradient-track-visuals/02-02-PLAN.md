Update KeyframeLayerRenderer to draw contrast outlines behind keyframe circles for visibility on any gradient color.

**Changes to make:**

1. Add helper method to calculate perceived brightness:
```csharp
/// <summary>
/// Calculates perceived brightness of a color (0.0 to 1.0).
/// Uses standard luminance formula.
/// </summary>
private double GetBrightness(int r, int g, int b)
{
    // Perceived brightness formula (ITU-R BT.601)
    return (0.299 * r + 0.587 * g + 0.114 * b) / 255.0;
}
```

2. Update Draw() method to add contrast outline before filling keyframe:

In the foreach loop for keyframes, after calculating `rgb` and `color`:

```csharp
// Determine contrast color based on keyframe color brightness
var brightness = GetBrightness(rgb.r, rgb.g, rgb.b);
var contrastColor = brightness > 0.5 ? Colors.Black : Colors.White;

// Draw contrast outline (slightly larger than keyframe)
ds.FillCircle(new Vector2(x, y), radius + 2, contrastColor);

// Draw filled keyframe circle (existing)
ds.FillCircle(new Vector2(x, y), radius, color);

// Draw stroke (existing)
ds.DrawCircle(new Vector2(x, y), radius, strokeColor, strokeWidth);
```

**Key details:**
- Contrast outline is 2px larger than keyframe radius
- White outline on dark colors (brightness <= 0.5)
- Black outline on bright colors (brightness > 0.5)
- Drawn BEFORE the keyframe fill, so it appears behind
