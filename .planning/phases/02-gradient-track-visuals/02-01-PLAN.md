Create GradientTrackRenderer.cs in Views/Rendering/ following the established renderer pattern.

**Class structure:**
- Namespace: HueWindows.Views.Rendering
- Public class GradientTrackRenderer
- Main Draw method accepting: CanvasDrawingSession ds, IEnumerable<TrackViewModel> tracks, float zoomLevel, float trackHeight, float durationSeconds

**Core methods to implement:**

1. `Draw()` - Main entry point, iterates tracks and draws gradient strips
   - For each track with keyframes:
     - Draw solid color extension before first keyframe (if first keyframe > 0s)
     - Draw gradient segments between adjacent keyframes
     - Draw solid color extension after last keyframe (if last keyframe < duration)

2. `DrawGradientSegment()` - Draws single gradient between two keyframes
   - Create CanvasLinearGradientBrush with eased gradient stops
   - Use FillRoundedRectangle with pill shape (cornerRadius = height/2)
   - Draw subtle dark border (1px, Color.FromArgb(80, 0, 0, 0))
   - Dispose brush after use with `using` statement
   - Handle very short segments (< 5px): fall back to solid midpoint color

3. `CreateEasedGradientStops()` - Generates gradient stops with easing
   - Use 15 stops for smooth visual
   - For each stop position (0.0 to 1.0):
     - Apply Easing.Apply(position, endKeyframe.Transition) to get eased t
     - Interpolate color from start to end using eased t
   - Special case for TransitionStyle.Instant: hard cut at 99% position

4. `DrawSolidSegment()` - Draws solid color extension (before first/after last keyframe)
   - Use CanvasSolidColorBrush
   - Same pill shape and border as gradient segments

5. `InterpolateColor()` - Linear RGB interpolation between two HueColors
   - Convert HueColor (xy) to RGB using existing HueColorToRgb pattern from KeyframeLayerRenderer
   - Lerp R, G, B channels independently
   - Return Windows.UI.Color

6. `HueColorToRgb()` - Copy the existing xy-to-RGB conversion from KeyframeLayerRenderer
   - Same XYZ to sRGB conversion matrix

**Key implementation details:**
- Gradient shows hue only (ignore brightness in visualization per CONTEXT.md)
- Same-color adjacent keyframes render as solid block (no artificial variation)
- All brushes must be disposed (use `using` statements)
- Render order: solid extension -> gradient segments -> solid extension (but this is one continuous strip visually)
