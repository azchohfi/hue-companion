<objective>
Consolidate all XY-to-RGB conversions to use HueColor.ToRgb() consistently.

Purpose: Fixes COLOR-01 (gradient bar mismatch). The codebase has three different XY-to-RGB conversion implementations using different color matrices. GradientTrackRenderer and KeyframeLayerRenderer use a Wide Gamut RGB matrix while HueColor.ToRgb() uses the correct sRGB D65 matrix. This causes the same HueColor to display differently in the picker vs. the gradient bar.

Output: Both renderers use HueColor.ToRgb() for all color conversions, eliminating visual inconsistency.
</objective>

3. Update InterpolateColor() to use HueColor.ToRgb():
```csharp
private Color InterpolateColor(HueColor startColor, HueColor endColor, double t)
{
    var (sr, sg, sb) = startColor.ToRgb(1.0);
    var (er, eg, eb) = endColor.ToRgb(1.0);

    // Linear RGB interpolation
    var r = sr + (er - sr) * t;
    var g = sg + (eg - sg) * t;
    var b = sb + (eb - sb) * t;

    return Color.FromArgb(255, (byte)r, (byte)g, (byte)b);
}
```

Note: The interpolation is now in byte space (0-255) rather than linear (0-1), which matches how the colors are displayed. This is acceptable for visual purposes.
