# Generated Scene Files

This directory contains raw LLM-generated scene JSON files.

## Usage

1. Copy the prompt from `../scene-generator-prompt.md`
2. Append your scene description at the bottom
3. Submit to an LLM (Claude, GPT-4, etc.)
4. Save the output JSON here with naming convention: `scene_<name>.json`
5. Test by importing into Scene Builder or copying to `src/HueWindows/Assets/Scenes/`
